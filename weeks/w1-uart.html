02Cortex-M7 레지스터

S32K312의 CPU 코어는 Arm Cortex-M7(32비트, ARMv7-M, Thumb-2)이에요. 레지스터를 눌러서 역할을 확인해 보세요.

벡터 테이블 0번은 초기 스택 포인터, 1번은 Reset handler 주소예요. 리셋되면 Reset → Vector Table → Reset Handler → Runtime Init → main() 순서로 C 프로그램이 시작돼요.

03전원이 들어와서 main()까지

부팅 흐름

BAF(Boot Assist Flash)는 NXP가 칩에 넣어 둔 부팅 도우미 코드, IVT(Image Vector Table)는 부팅 이미지와 사용자 코드 진입 정보예요.

클럭 트리와 PLL Lock

클럭은 FIRC / SIRC / FXOSC → PLL → System · Bus · Peripheral Clock으로 흘러가요. PLL은 입력 클럭을 몇 배로 키워서 빠른 클럭(코어 120 MHz)을 만드는데, 목표 주파수에 고정(Lock)되기 전에 나눠 주면 안 돼요.

04메모리 맵: 주소가 다 RAM은 아니다

MCU에서 주소는 RAM만 뜻하지 않아요. 영역을 눌러 보세요. 주변장치(Peripheral) 영역 안에는 UART, GPIO, I2C의 제어 레지스터가 들어 있어요.

05UART 프레임: 8-N-1

UART는 클럭 선 없이 TX/RX만으로 주고받는 비동기 직렬 통신이에요. 그래서 양쪽이 같은 속도(baud rate)를 미리 약속해야 해요. 쉬는 동안 선은 HIGH, Start(LOW)로 시작해서 데이터 8비트를 LSB부터 보내고, Stop(HIGH)으로 끝나요.

06printf가 PC까지 가는 길

MCU에는 화면이 없어서 printf()가 그냥은 아무 데도 안 나가요. 그래서 printf가 마지막에 부르는 저수준 함수 _write()를 직접 만들어서, 바이트를 LPUART6로 보내요(retargeting). 보드의 OpenSDA 칩이 그걸 USB 가상 COM 포트(VCOM)로 PC에 넘겨줘요.
